# Agent skills

Cursor loads skills from this folder. Claude Code finds `apple-design-rn` through a short pointer at `.claude/skills/apple-design-rn/SKILL.md`. Edit only the copy in this folder.

## Installed

- [apple-design-rn](apple-design-rn/SKILL.md) — Apple-grade UI guidance for this Expo app and its web landing page. For any UI work, follow that file.

## Not vendored

- [dickwu/apple-design-skill](https://github.com/dickwu/apple-design-skill) has no license file, so it is not committed. Install it with `npx skills add dickwu/apple-design-skill`.
- [twostraws/swiftui-agent-skill](https://github.com/twostraws/swiftui-agent-skill) (MIT) is SwiftUI-only. This is an Expo app, so that skill is not installed.
